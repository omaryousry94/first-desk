# ACV Fixer - Intelligent ACV Calculation Platform

A modern, responsive Next.js application for streamlining Actual Cash Value calculations with AI-powered analysis and error detection.

## 🚀 Features

- **Lightning Fast Processing**: Process thousands of ACV calculations in seconds
- **Error Detection & Fixing**: Automatically detect and fix common calculation errors
- **Smart Depreciation Models**: Advanced depreciation calculations with industry-specific models
- **Real-time Validation**: Instant validation with detailed reports
- **Market Data Integration**: Access real-time market data for accurate valuations
- **Team Collaboration**: Collaborate with your team and maintain audit trails

## 🛠️ Tech Stack

- **Framework**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Font**: Geist Sans & Geist Mono

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd acv-fixer
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
